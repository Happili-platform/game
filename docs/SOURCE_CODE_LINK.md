# GAMe — Source code availability

The official source repository for this community edition is:

https://github.com/Happili-platform/game

The application's login, password and primary UI should expose an accessible
`Source code (AGPLv3)` link to the corresponding source of the version being
run. The link in this repository refers to the community upstream; operators
of modified network-hosted versions must ensure the corresponding source for
their deployed modifications is available as required by AGPLv3.

Example:

```html
<a href="https://github.com/Happili-platform/game"
   target="_blank" rel="noopener noreferrer">Source code (AGPLv3)</a>
```

The public source repository does not imply that this alpha release is safe for
internet-facing deployment. See SECURITY.md and docs/security-gaps.md.
