# Backlog — moved to Product Roadmap

The active, prioritized GAMe backlog is now maintained in **[`product_roadmap.md`](product_roadmap.md)**. That document owns the release sequence, acceptance gates and cross-functional workstreams from v0.3.3 onward.

The previous backlog has been preserved as **[`backlog-legacy.md`](backlog-legacy.md)** for historical requirements and traceability. It includes early assumptions from v0.1 and v0.3.0, some of which are no longer aligned with the active single-company product direction. Do not use the legacy backlog as the current release plan.
