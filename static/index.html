Renewable workload authentication — recommended

GitHub App credentials (encrypted, localhost only)

The server discovers the Installation ID automatically. Private key never appears in inventory or API responses.

Atlassian service account authentication (encrypted, localhost only)

Enable API-key authentication in Atlassian Administration → Rovo → MCP server → Authentication first. The connector only calls initialize and tools/list, not tools/call.

Microsoft Entra credentials (optional — localhost only)

Enter all three to save encrypted credentials for this connection. Leave blank to use host identity or retain already saved credentials when editing. Secrets are never shown again.

AWS IAM Identity Center — temporary credentials (optional, localhost only)

From IAM Identity Center → AWS access portal → temporary credentials. Enter all three fields, or leave blank to use AWS role/profile/host credentials. Optionally specify the session expiration in your Mac's local time; temporary tokens do not renew themselves. Blank fields on Edit retain encrypted credentials.

Google Agent Engine — service account credentials (optional, localhost only)

Leave blank to use Google Application Default Credentials (ADC) or workload identity on the host. Only a JSON service account key is accepted here; workload-identity configuration files are configured on the host. Never paste a production key.

Local mode is loopback-only and uses the legacy tenant. Workload connections use host identities and renewable tokens. Static credentials (development only) are encrypted in SQLite using a separate key. API-only OIDC mode enforces tenant membership and roles, but a full enterprise browser sign-in flow, deployment isolation and production hardening remain to be implemented.

Provider type cannot be changed. Changing project or region clears previously discovered records for this connection, after confirmation. External agents are never modified.
